# Comandos Bot

Segundo bot do projeto, focado em comandos utilitários.

## Comandos disponíveis
- `/start` - Inicia o bot
- `/help` - Mostra lista de comandos
- `/echo <texto>` - Repete o texto enviado

## Configuração
Use as mesmas variáveis do `.env` principal. Defina `BOT_TOKEN_COMANDOS` quando este bot usar um token diferente do Super Bot.

O `/menu` usa o mesmo Mini App configurado em `MINI_APP_URL`. Se a variável não estiver definida, o bot mostra um menu textual organizado por categoria.
